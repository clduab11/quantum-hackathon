# C59 chemistry through the exact J=4 compiler (PRA-294)

`tasks.dfthcsos.c59` generates 19 exact four-word ANGLE circuits from mrmeows'
published C59 factor (`qcc-1375-open-circuits` v8, R=10, B=129, C=59, 8-bit
words). It copies the declared non-circuit NPZ unchanged. No circuit,
decomposition certificate or audit is an input. Source versions, URLs, hashes
and licence observations are in `ledger/manifests/inputs/pra294-c59.json` and
`notices/30-dfthcsos.txt`.

## Prerequisites and use

Run `uv sync`, then install the organizer Kickmix/verifier paths with
`uv run python scripts/install_kickmix.py /home/cld-main/work/vqcc-data/google-verifiable-quantum-circuit-compilation`.
Place v8's `circuits/dfthcsos/submission.npz` at
`/home/cld-main/work/vqcc-data/inputs/mrmeows/qcc-1375-v8-C59-submission.npz`.
The generator pins its hash.

```sh
uv run python -m tasks.dfthcsos.c59 --help
uv run python -m tasks.dfthcsos.c59 --data /home/cld-main/work/vqcc-data --out /tmp/pra294-build --dry-run
uv run python -m tasks.dfthcsos.c59 --data /home/cld-main/work/vqcc-data --out /tmp/pra294-build
OPENBLAS_NUM_THREADS=1 uv run pytest -q tests/test_c59_compiler.py
```

Dry run validates the hash and compiles in memory without writing files. A
normal build (about 6 s) writes only `OUT/dfthcsos/submission.npz` and
`angle_k_0..18.kmb`, and prints file hashes and resource counts as JSON. A hash
mismatch, a failed exact plan, an oversized layout or a nonempty output
directory raises an error and exits nonzero. G5 supplies its isolated data root
through `VQCC_DATA`. No download, GPU work or submission occurs here.

## Exact construction

Batches are four words (75 angles → 19 circuits). Split the 11 selection bits
into four low and seven high bits: 85 high monomials (78 cached with ANDs) and
15 low monomials. The 28 output bits form a 85 × 15 × 28 GF(2) coefficient
tensor. The low monomials are used in two stages, 1–11 then 12–15, so a
seven-qubit low cache is enough: after stage 1, four low ANDs are erased by HMR
and their qubits recomputed as 12–15.

For each stage a planner chooses kernel relations of the tensor, builds the
rank-two templates `(v⊗ℓ1, v⊗ℓ2)` that annihilate them, and selects a paired
basis. Each pair costs one Toffoli through
`(h1+l2)(h2+l1) + h1*h2 + l1*l2 = h1*l1 + h2*l2`; the same-side corrections use
cached monomials and Clifford gates. Stage 1 uses `plan_balanced` (degree-
balanced relations over all 3-subsets), stage 2 `plan_tensor` (cyclic windows).
A plan is accepted only after bit-exact reconstruction of the tensor.

Each circuit is 135 + 50 paired products plus 78 + 11 cache ANDs: **274
Toffolis, 128 qubits**. The XOR oracle holds for arbitrary incoming word
registers. The plan parameters are the 19 first-stage seeds and the constant
stage sizes in `c59.py`, taken from v8's cost-first-shape-screen certificates
(only their `first_plan`/`second_plan` fields). That screen's NPZ has the same
`angle_words` as C59, so its seeds give the same plans. Our 19 circuits are
byte-identical to mrmeows' published cost-first-shape-screen circuits (dataset
circuits, not competition-package circuits).

Why a new compiler: PRA-280's `paired_qrom` is J=3. On C59 it gives 25
circuits × 257 Toffolis and 7.777×, below the 8.0× floor. Lifting its 3-word
guard gives 313 Toffolis and 132 qubits (over the cap). Measured on PRA-294.

## Verification and hand-off

Use `configs/gates/pra294-c59.yaml`: `pra293-fused-invsqrt.yaml` with only the
chemistry G1 hook, generator, input pin and G4 changed (pinned by
`tests/test_c59_compiler.py`). All G0–G5 gates are non-waivable. G3 requires
87,424 chemistry shots at the fixed public salt. G4 keeps PRA-293's checks
and adds chemistry ≥ 8.0×. G5 stages only the declared NPZ and rebuilds all
circuit bytes from the generator commit. Results:
`ledger/evidence/pra294-c59/README.md`.

Only the board merges. To return the shipped bundle to `pra293-fused-invsqrt`,
run `bash ledger/evidence/pra294-c59/rollback/rehearsal-command.sh`; it changes
only `dfthcsos/`. A `git revert` restores source only, not a bundle or a Kaggle
submission.
