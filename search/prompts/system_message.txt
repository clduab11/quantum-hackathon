# What the program must do
`build_family(words, source_brot)` receives the (3976, 75) integer table of angle words (12-bit) read from the
declared factor file and returns `(circuits, report)` (or `(circuits, report, table)` where `table` is the
integer word table the circuits actually load): kickmix circuits `angle_k_0 .. angle_k_{K-1}` with
K = ceil(75 / J). The fixed wrapper writes them plus `submission.npz` and checks the 128-qubit cap.
Public register contract (checked by the verifier, identical in every circuit):
- a register named `selection` with exactly 12 qubits (3976 addresses);
- registers `word_0 .. word_{J-1}`, each `brot` qubits, J = words per circuit (same J and brot everywhere);
- circuit k maps |a>|z> to |a>|z XOR delta_k(a)> where delta_0 = batch_0 and delta_k = batch_k ^ batch_{k-1}
  (`batch_deltas(table, J)` returns exactly these), so after circuits 0..k the word registers hold batch k of
  row `a`; batch k holds columns k*J .. k*J+J-1 of the row, in that order (no column permutation; padding
  columns stay zero);
- the loaded words must be the same on every shot of an address: no measurement-dependent words
  (measurement with HMR is fine when the correction is Clifford and classically conditioned);
- after each circuit the selection register is unchanged, every ancilla is back to |0> (freed), the
  global phase is unflipped; applying the K circuits in reverse order must clear the word registers;
- no Z_POW rotations (phases must be multiples of pi); no circuit may use more than 128 qubits.

# Cost model (lower cost = higher ratio; the reference cost is 3,355,599,588.3155365 = ratio 1.0)
cost = lambda_eff * T_total * Q_total
- lambda_eff is set by the words the circuits load (49.3014 for the 12-bit words; smaller brot changes it
  and, for this factor, breaks the 20 mHa accuracy gate: 11 and 10 bits are rejected).
- T_total = (Toffoli-like gates executed per shot, summed over all circuits, FORWARD AND REVERSE pass)
  + 13,757 fixed (outer prep 846 + inner prep 9,461 + Givens 2*75*(2*brot-1) = 3,450 at brot 12).
  Toffoli-like = CCX, CCZ, CSWAP; a conditioned gate counts only on shots whose condition bit is set;
  `init_and`/`del_and` pairs cost one Toffoli (the `del_and` uncompute is measurement-based and free).
- Q_total = 90 + J*brot + max(544, ANGLE temporaries) = 634 + J*brot as long as the ANGLE circuits stay
  under the cap (their temporaries never approach 544). So Q is decided by J alone and T by how cleverly
  the XOR-difference tables are loaded. Reference: J=8, 10 circuits, T 93,237, Q 730.
  Best verified so far: J=9, exact ANF loader, T 85,109, Q 742, ratio 1.0778 (see the notes).
- Quick arithmetic: ratio = 68,063,010 / (T_total * Q_total). To beat 1.0778 you need T*Q < 63.15M.

# How you are evaluated
Stage 1 builds your program and runs static checks (qubit cap, register layout, Z_POW, the G2 cost proxy).
Stage 2 runs the official verifier with 2 shots per address; stage 3 runs it in full (64 shots per address,
254,464 shots). `combined_score` is the verified cost ratio only after stage 3 passes; otherwise it is a
small penalised number, so an unverified program never beats a verified one. The "Last Execution Output"
section shows the evaluator's artifacts for the current program (summary, program report, proxy, verifier
JSON, stderr): read it before changing anything. Features `q_bin`/`t_bin` are Q_total and T_total; programs
with different (Q, T) trade-offs are kept even when their ratio is lower.
